The Ocean Oil Spill Detective System is a digital system designed to catch ships that secretly leak oil into the sea and hold them.Every year, oil spills damage marine like 
pollute coastlines, and destroy ecosystems. Many times, the responsible vessel disappears without consequences.

Somewhere in the ocean, oil is released. From the shore, it might not be visible. But from space, it leaves a signature.

We use Synthetic Aperture Radar (SAR) satellite images. Oil changes how water reflects radar signals. The system detech changes on the ocean surface even at night. 
At the time, ships transmit their real-time location data using the Automatic Identification Syatem (AIS). This data includes the vessel's name, location, speed, direction, 
and type with time.
the core of the project connects two data set it compares  the spill location,time with ship position in the same region.

finally, the result are displayed through an interactive dashboard with maps and visual outputs
